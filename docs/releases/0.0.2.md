# Claude Code and Codex repository release 0.0.2

Prepared October 20, 2026. Publication is pending the signed CLI 0.0.2 build and
verified artifact import; the candidate must not be tagged before that completes.

## Changes

- Local grouped requests collect 2–8 named credentials atomically on one form.
  Forgetting the group or any member erases the whole group.
- Command execution keeps browser approval by default. Owners may opt into
  supported Claude Code permission prompts or Codex approval settings, which
  can authorize automatically. Secret entry stays in the isolated browser.
- Status cards show grouped field names and structured command outcomes.
- Release packaging retains the card module and exact artifact checksums.

## Validation so far

- Six release-import regression tests and four approval-helper tests passed.
- Six Node card-state tests and the package-content check passed.
- Official plugin, MCP, Registry, and Cline schema checks passed on the candidate.
- A redacted Gitleaks scan found no leaks in the public integration candidate.
- The grouped-login model case passed both arms on October 15. Full model scores
  remain below the target, with tool-name grader limitations and missed handoff
  calls documented in `evals/RESULTS.md`; no improved score is claimed here.

## Remaining release checks

Import actual signed 0.0.2 bytes; verify checksums and build provenance; rebuild
and validate the pinned package; run clean public and immutable-tag installations
and upgrade checks in isolated Claude Code and Codex profiles.

A fresh interactive human fill/approve/use flow and installed-card visual
acceptance remain separate checks. No vendor-curated listing approval is claimed.
Phone/remote relay stays disabled on the public service.
