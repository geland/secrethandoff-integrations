# Claude Code and Codex repository release 0.0.2

Prepared October 20, 2026 for signed CLI 0.0.2.

## Artifact identity

- Binary source/tag: `geland/secrethandoff`, `cli-v0.0.2`, public commit
  `fe540e24c082bcdfe70f8ada879e217d7b836676`.
- Protected signing workflow: https://github.com/geland/secrethandoff/actions/runs/39519007654
- All fourteen public files match the workflow release artifact byte for byte;
  all twelve package hashes pass the release importer.
- All twelve package attestations verify against the exact tagged workflow and
  public source commit, with GitHub-hosted runners. GitHub CLI 2.102.1 was used
  in a temporary directory because installed 2.48.0 cannot parse the current
  Sigstore root key type. The installed CLI was not changed.
- The downloaded Apple Silicon binary reports 0.0.2 and passes
  `codesign --verify --strict --check-notarization`.
- `release-lock.json`, `server.json`, and all client manifests pin version 0.0.2.
  Fresh mocks from the signed binary expose nine tools.

## Changes

- Local grouped requests collect 2–8 named credentials atomically on one form.
  Forgetting the group or any member erases the whole group.
- Command execution keeps browser approval by default. Owners may opt into
  supported Claude Code permission prompts or Codex approval settings, which
  can authorize automatically. Secret entry stays in the isolated browser.
- Status cards show grouped field names and structured command outcomes.
- Release packaging retains the card module and exact artifact checksums.

- Six Node card-state tests and the package-content check passed.
- A fresh harmless Codex 0.155.1 host probe delivered the tool under an allow

publication checks. Both isolated 0.0.1 baseline installations passed launch,
eight-tool inventory, missing-secret refusal, and synthetic hook checks.
