## Acceptance boundaries

These checks establish package installation, protocol wiring, and pure card/hook
behavior. A fresh interactive human fill/approve/use flow in each client and
visual acceptance of the installed status card remain separate checks. The
existing signed CLI already completed a local browser-approved synthetic handoff
at launch; that does not establish every host's UI behavior. Windows and Linux
fresh-client installs were not run in this release check.

No vendor-curated directory approval is claimed. Phone/remote relay remains
disabled on the public service. Other client listings are drafts.

## Reproduce

Install Python requirements in a virtual environment. Run `scripts/test_release.py`,
`scripts/validate.py --release`, `scripts/package.py --release`, and
`scripts/test_package.py`. Set `SECRETHANDOFF_TEST_TYPESCRIPT` to a TypeScript
module and run Node 24 with `--test tests/card-state.test.mjs`.

After a clean client installation, run `scripts/check_installed.py` with the
cached plugin directory and the verified 0.0.1 executable path.
